# Proyecto Final — Razonamiento con IA

Notebooks de análisis (aprendizaje supervisado y no supervisado) para dos bases de datos:
cáncer de mama (ya terminado) y corpus de hojas (en desarrollo).

@docs/HANDOFF.md

## Comandos
- Entorno: `.venv\Scripts\Activate.ps1` y luego `pip install -r requirements.txt`
- Ejecutar el notebook completo de principio a fin: `jupyter nbconvert --to notebook --execute --inplace notebooks/hojas.ipynb`

## Reglas
- El estilo de código y de documentación lo define `notebooks/cancer_mama.ipynb`. No lo modifiques salvo que se te pida.
- Trabaja una sección a la vez. Ejecuta las celdas y verifica las salidas antes de pasar a la siguiente.
- Todo el texto va en español, en el mismo tono que el notebook de referencia.
- Nunca escribas cifras a mano en el markdown o en las tablas sin haberlas calculado en una celda.
